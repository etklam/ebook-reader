# ER-006｜書庫隱藏手動標記已讀的作品

- 優先級：P2
- 工作量：中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為會員，我希望在公開書庫找新書時，暫時隱藏自己已讀完的作品。

提供預設關閉的「隱藏已讀」條件，僅依本人書架中手動設定為「已讀」的作品判定。章節停留時間、已讀章節紀錄與閱讀進度均不自動代表全書已讀；不在書架內或狀態為想讀／閱讀中／擱置的作品繼續顯示。

## 驗收條件

- [x] 會員開啟條件後，清單與符合總數排除自己標記為已讀的作品；關閉後恢復。
- [x] 只套用本人閱讀狀態；其他會員與訪客不能推知或使用該帳號的私人狀態。
- [x] 條件與既有搜尋、分類、標籤及排序可組合，作用於全部候選作品而非目前已載入頁面。
- [x] 個人化查詢與游標綁定帳號及條件，快取不跨帳號共用；登出或換帳號後重置個人化結果。
- [x] 訪客入口提供登入提示；未登入請求此私人篩選時回傳明確結果，不假裝成功套用。
- [x] 手動將作品從已讀改為閱讀中後，重新查詢即可再次出現；不會修改收藏、追更或進度。
- [x] 驗證兩個帳號不同已讀狀態、多頁清單及篩選總數一致性。

## 不在範圍

自動判定讀完、永久封鎖作品，以及排行榜或相似作品的個人化。

## 依賴

無，可獨立開始；與 ER-005 共用篩選邏輯的變更需協調整合。
