# ER-003｜書籤備註編輯與按作品整理

- 優先級：P1
- 工作量：小至中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為讀者，我希望替書籤記下人物、伏筆或感想，並能在自己的書籤中找回某部作品的備註。

目前後端已有書籤備註與修改能力，閱讀器建立書籤時沒有填寫備註，書籤清單也沒有編輯入口。補齊新增後填寫、既有備註編輯／清除，以及按作品篩選的完整操作。保留一鍵建立書籤的便利；備註可留空。

## 驗收條件

- [x] 閱讀器建立書籤後可選擇填寫備註；略過備註仍保留書籤，不改變閱讀位置。
- [x] 我的書籤可編輯與清空備註，500 字限制與後端一致，顯示剩餘／目前字數，儲存失敗保留輸入。
- [x] 編輯備註只修改備註，不覆寫原有章節、修訂與段落錨點。
- [x] 按作品篩選作用於伺服器端的全部本人書籤，包含原清單上限之外的紀錄；需要時提供分頁與載入更多。
- [x] 未登入與非擁有者不能讀寫私人備註；文字作為純文字顯示。
- [x] 刪除後復原保留備註與原錨點；涵蓋新增、編輯、清空、篩選及錯誤重試的實際使用路徑。

## 不在範圍

文字範圍畫線、公開筆記、社群分享、筆記匯出與 AI 摘要。

## 依賴

無，可獨立開始；優先沿用既有書籤備註與授權契約。
