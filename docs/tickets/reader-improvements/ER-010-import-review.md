# ER-010｜匯入套用前的逐章差異與衝突決策

- 優先級：P2
- 工作量：中至大
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為管理員，我希望在套用匯入前看懂哪些章節會修改，並逐項解決匹配衝突。

目前比對介面主要顯示統計數字，待決項目出現在套用失敗訊息；後端已有人工 resolutions 契約。提供可篩選的章節清單、按需展開的站方／來源正文差異，以及沿用既有契約的人工對應／排除選項。所有阻塞項目處理後，才可套用已檢視的方案。

## 驗收條件

- [x] 套用前即可列出相同、有修訂、新章、待決與來源缺失項目；支援分頁／有界載入，不一次下載全部正文。
- [x] 展開單章可核對站方與來源文字、插入位置及資源變更；圖片 marker 不作一般正文誤導顯示。
- [x] 歧義與結構衝突只提供後端已支援的人工決策，不自動猜測章節身分；未支援情境明確指引修正來源後重新分析。
- [x] 待決項尚未解決時阻止套用並指向該項；來源缺失不暗示刪除，無錨點追加需要明確選擇。
- [x] 套用前可核對增量／覆蓋的實際影響與被排除清單；後端仍獨立驗證所有決策與權限。
- [x] 基準編輯版本或分析版本改變時，舊決策不能直接套用，提示重新比對；同一次提交重試沿用冪等識別，避免重複建立修訂。
- [x] 驗證歧義對應、結構衝突、來源缺失、中間插章、版本衝突及提交重試；套用成功仍須另外發布才影響公開內容。

## 依賴
