# ER-012｜書內搜尋提早回傳與接續分頁

- 優先級：P2
- 工作量：中至大
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為搜尋長篇內容的讀者，我希望先看見第一批命中章節，不必每次等整本掃完。

目前每次請求讀取所有章節正文，雖然每頁只回傳 50 個命中章節，仍為了精確總數掃完整本。改成找到本頁及下一頁存在所需的命中後即可返回，提供綁定查詢與可讀版本的接續游標。介面顯示本頁結果及「還有更多」，不把已掃描結果冒充總數；下一頁從先前掃描位置接續。保留每章第一個匹配、繁簡互查與段落連結語義。

## 驗收條件

- [x] 使用有真實正文物件的大型作品，記錄修改前後的章節／位元組讀取量、搜尋 p50／p95、資料規模與併發條件；不以缺正文的合成基線代表本功能。
- [x] 首頁命中充足時，找到 50 筆加下一頁判定所需命中後停止；允許已在途的有界批次完成，不再為精確總數掃完整本。
- [x] 後續頁從接續位置查找，不反覆讀取前頁已掃描的所有正文；游標攜帶／重讀 lookahead 時不遺漏該命中。
- [x] 游標綁定作品、正規化查詢、有效發布版本及必要的草稿版本／權限範圍；每頁重新授權。篡改、錯用及版本失效均有明確處理。
- [x] 改變查詢後重置分頁，舊回應不覆蓋新結果；保留可用的上一頁操作，且不假造完整結果總數。
- [x] 繁簡高亮、段落連結與每章第一個命中語義不變；公開查詢不讀取未發布草稿或歷史版本。
- [x] 掃描範圍內正文缺失時明確回報，不能偽裝沒有結果；早停後未掃描範圍不宣稱已完成完整性檢查。
- [x] 驗證 0／49／50／51／多頁命中、稀疏命中、最後一章命中與查詢中發布新版本；無命中仍可能掃完整本，報告須如實呈現。

## 不在範圍

獨立搜尋服務、語義搜尋、預設導入中文全文索引或任意增加資料庫索引。若稀疏查詢仍不符需求，使用本票量測證據另開發布版索引／不可變內容快取 ticket。
