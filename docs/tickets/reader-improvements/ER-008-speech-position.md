# ER-008｜從目前段落朗讀與續播

- 優先級：P2
- 工作量：中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為讀者，我希望從正在看的段落開始聽書，停止後也能接續，而不是每次回到章首。

保留「朗讀本章」，另提供「從目前段落朗讀」。同一閱讀器會話內記住停止時的朗讀段落，提供續播；以段落為單位顯示目前朗讀位置。沿用系統語音、語速、睡眠定時與自動下一章。

## 驗收條件

- [x] 從目前段落開始時，使用閱讀器既有錨點，對捲動及分頁模式皆有效；「朗讀本章」仍從章首開始。
- [x] 朗讀純文字，略過圖片 marker；維持轉換後文字與 canonical 段落索引的對應，不回寫正文。
- [x] 目前朗讀段落有不改變排版的可辨識提示，不自動搶走焦點或強制捲動讀者畫面。
- [x] 暫停／繼續沿用系統播放位置；停止後續播從所記錄段落重新開始，介面明確表達段落級續播。
- [x] 手動切章清除舊章續播位置；自動下一章從新章首開始；切換繁簡或修訂變動時不使用失效文字偏移。
- [x] 關閉設定面板不停止播放；睡眠定時、播放失敗、語音不支援的既有處理仍可用。
- [ ] 驗證長段落分片與自動下一章，並記錄目標手機的實際語音行為；不承諾裝置未支援的鎖屏／背景播放。

## 不在範圍

雲端 TTS、逐字高亮、跨裝置語音進度與音訊檔下載。
