# ER-002｜依閱讀進度調整下一章預載

- 優先級：P1
- 工作量：小至中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為讀者，我希望讀完一章後能快速接續下一章，並避免下載已過期而無法重用的預載內容。

目前開章成功後立即預載下一章，但預載只保留 30 秒；閱讀超過期限後切章會重新取得正文。改成接近章末才觸發預載，並保留有界快取與版本新鮮度約束。初始觸發條件採捲動進度達 80%，或分頁模式進入最後兩頁；短章可立即觸發。章節內重排不應反覆下載。

## 驗收條件

- [x] 讀者在章節前段停留超過 30 秒後接近章末，才發出預載請求；捲動、分頁兩種模式皆可觸發。
- [x] 預載仍有效且未失敗時，切章共用同一請求或結果；在途請求不重複建立。
- [x] 未接近章末就直接切章、預載失敗或過期時，仍可正常取得正文並重試，不阻塞閱讀。
- [x] 保留明確的有界快取與到期政策；發布版本改變、重訪作品與帳號／可見性變更時不得無期限重用舊內容。
- [x] 預載不寫入閱讀進度、已讀紀錄或閱讀統計；反覆切換設定不造成重複請求風暴。
- [x] 以可控時間測試與網路請求紀錄，展示「長時間閱讀後接近章末再切章」的前後差異，另記錄一次冷載入／命中預載的切章耗時與測試條件。
