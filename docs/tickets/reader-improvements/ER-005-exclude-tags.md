# ER-005｜書庫排除指定標籤

## 要做的事

身為找書的讀者，我希望保留想看的題材，同時排除不喜歡的標籤，例如「玄幻，但不要系統文」。

在現有書庫篩選加入「排除標籤」。包含標籤繼續遵守全部／任一模式；作品命中任一排除標籤即排除。此功能是現行規格「第一版不加入排除標籤」的後續擴充，實作時同步更新該契約。

## 驗收條件

- [x] 可新增、移除排除標籤，已套用條件以明確的「排除」文字顯示，不只靠顏色。
- [x] 與關鍵字、分類、狀態、包含標籤組合後，清單與符合總數採相同判斷。
- [x] 同一標籤不會同時處於包含與排除；切換角色有可見回饋，不靜默改變其他條件。
- [x] 排除條件保存於網址並納入游標綁定；更改條件重置分頁，錯用舊游標不回傳混合結果。
- [x] 無結果時保留條件且可逐項移除；訪客與會員對相同公開條件取得一致結果。
- [x] 沿用既有標籤數量上限或明確記錄新增上限，非法／停用標籤處理與現有包含標籤一致。
- [x] 驗證「玄幻＋排除系統」、多個排除標籤、無標籤作品，以及包含全部／任一兩種組合。
