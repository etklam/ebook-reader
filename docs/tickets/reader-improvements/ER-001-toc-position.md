# ER-001｜目錄直接定位目前章節與最新章

- 優先級：P1
- 工作量：中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為長篇讀者，我希望讀到後面的章節時，打開目錄即可看見目前位置，也能直接查看最新發布章節。

目前目錄每次從前 100 章開始載入，只有目前章節已在載入清單內才會捲到該項。改成以目前章節為中心取得有界範圍，支援向前、向後載入，以及「回到目前章節」「前往最新章目錄位置」。作品詳情頁沒有閱讀中章節時仍從開頭顯示。定位目錄本身不改變正文或閱讀進度。

## 驗收條件

- [x] 對 5,000 章作品，在第 847 章打開目錄，第一次載入即可看見並標示該章，不必先逐批載入前 846 章。
- [x] 可取得該範圍前後的章節，連續翻看沒有重複或遺漏；不一次下載整本目錄或章節正文。
- [x] 最新章依有效發布快照的閱讀順序取得，不依章號數值或草稿判定。
- [x] 點選章節後才切換正文；定位按鈕、載入與重試均不更新閱讀進度或已讀紀錄。
- [x] 目前章節已不在有效版本時有可理解的提示及可用的目錄入口，不無限載入。
- [x] 涵蓋第 1 章、中間章、最後一章、不規則章號，以及請求失敗後保留既有清單；390px 寬與鍵盤操作可用。

## 不在範圍

章名搜尋與倒序顯示由 ER-004 處理；不變更章節身分或發布模型。
