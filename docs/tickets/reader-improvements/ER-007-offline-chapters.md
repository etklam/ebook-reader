# ER-007｜預存接下來少量章節供離線閱讀

- 優先級：P3
- 工作量：大
- 類型：HITL
- 狀態：needs-triage

## 要做的事

身為通勤讀者，我希望在有網路時預存接下來 3 或 5 章，斷線後仍能開啟閱讀器並繼續閱讀。

這是超出既有記憶體預載的持久化功能，需要同時完成章節／必要圖片下載、可離線開啟的應用入口、下載狀態、儲存空間管理與恢復連線後的版本處理。

## 實作前待確認的決策

- 建議第一版只允許會員主動下載公開且已發布作品；是否包含 unlisted 作品由維護者決定。草稿不納入。
- 建議以章數 3／5 搭配全站離線資料的容量上限控制；容量數值與圖片是否全部納入須確認。
- 下架或授權改變時，已下載內容在完全離線期間無法得知變化；必須確認可接受的保留期限與重新連線清理政策。
- 確認原規格「暫不做完整離線下載」允許此有限範圍擴充，並記錄支援的裝置／瀏覽器。

## 驗收條件

- [ ] 上述決策有明確紀錄，才進入實作；介面與資料保留規則符合該紀錄。
- [ ] 下載前顯示章節範圍與容量資訊，下載中可見進度及失敗項目，完成後只有可完整開啟的章節標為已下載。
- [ ] 斷線並關閉／重新開啟頁面後，仍可由離線入口讀取已下載章節；未下載章節顯示可理解的提示。
- [ ] 內容與圖片以發布／修訂身分關聯；不得把新正文和舊資源混合。重新連線發現新版本時提供明確的更新行為。
- [ ] 可按作品清除下載；容量不足、瀏覽器回收資料及下載中斷均能恢復，介面不顯示不存在的下載成功狀態。
- [ ] 登出清除該帳號下載資料，換帳號不共用私有狀態；重新連線時重新檢查可讀權限與下架狀態。
- [ ] 離線閱讀進度先在本機保存；回線後依既有或已確認的同步政策處理，不宣稱離線期間已同步。
- [ ] 記錄目標手機的離線重開、圖片章節、容量失敗、回線更新與登出清除驗證結果；未執行真機項目明列。

## 不在範圍

整本下載、背景無限下載、DRM、離線管理後台及跨帳號共享離線書庫。

## 依賴

沒有其他 ticket 的硬性依賴；上述產品決策是實作前置條件。與 ER-002、ER-009 同時進行時需協調快取及同步契約。
