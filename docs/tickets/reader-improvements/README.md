- **P1**：優先改善日常閱讀；**P2**：接續功能；**P3**：選配擴充。這是排程優先級，不是事故嚴重度。
- **AFK**：範圍已具體化，可由 agent 接手；**HITL**：實作前需要人工確認 ticket 內列出的產品決策。
- AFK 狀態為 **implemented**，表示程式與自動驗證完成；真機 L3 尚未通過，ER-008 的真機語音條件保留未勾。HITL 維持 **needs-triage**。這些是本批文件標記，未修改專案級 tracker 或標籤設定。
- 工作量為相對估計，非工期承諾；開發時仍需檢查當時程式碼。

執行證據與限制見 [AFK 驗證紀錄](verification.md)。

## 共通約束與證據界線

- 位置沿用 `chapter_id + revision_id + paragraph_index`，必要時加段內比例；頁碼不是永久進度。
- 章節按編輯順序排列，保留不規則章號原文；不得把章號轉成數字推算身分或位置。
- 公開閱讀依目前有效發布快照；管理員草稿預覽與會員私有資料維持既有授權界線。
- 繁簡轉換只影響檢視，不回寫 canonical 正文；圖片 marker 與段落索引必須保留。
- 手機優先，觸控目標至少 44px，保留鍵盤操作、可辨識狀態及段落回錨。
- 效能 tickets 來自程式碼觀察，不代表本次已量測到卡頓或承諾加速比例。既有基線為單機合成資料，未涵蓋完整正文 I/O 與併發。
- 每張 ticket 只做與變更相符的驗證；瀏覽器自動化不等於完成真機 L3。涉及真機的結果必須記錄裝置與版本，未執行項目要明列。
