# ER-004｜目錄搜尋與正反排序

- 優先級：P2
- 工作量：中
- 類型：AFK
- 狀態：implemented（實作及自動驗證完成；真機 L3 仍待驗）

## 要做的事

身為長篇讀者，我希望以章名或原始章號找到章節，或從最新發布章節往前翻目錄。

在已能定位目前章節的目錄中加入搜尋與正序／倒序。搜尋涵蓋目前可讀版本的完整目錄，只查章名與原始標籤，不掃描正文。排序以編輯順序為準，切換條件不直接跳轉正文。

## 驗收條件

- [x] 尚未載入的章節也能被搜尋到；支援繁簡互查，結果保留章號原文及目前章節標記。
- [x] 搜尋與正反排序可組合，分頁結果無重複或遺漏；倒序是閱讀順序反轉，不是章名／章號字串排序。
- [x] 改變查詢或排序會重置分頁並忽略過期回應；沒有結果、載入失敗與載入中狀態可區分。
- [x] 清除搜尋後可返回目前章節附近；點選結果才導覽及更新進度。
- [x] 發布版本更新造成分頁失效時，明確提示重新載入，不混用不同版本目錄。
- [x] 驗證 5,000 章目錄、繁簡查詢、上下篇與小數章號，以及手機／鍵盤完整操作。

## 不在範圍

正文全文搜尋、模糊語義搜尋及章號正規化。
