## Anti-Patterns Verdict

Not AI slop. The system commits: ruled index rows instead of card grids, one
bronze accent, serif display against UI sans, tabular figures, 2px radii,
no gradient text, no glassmorphism, no eyebrows. DESIGN.md's anti-references
are actively honoured.

Deterministic scan: `detect.mjs` over `apps/web/src` returned 1 finding,
`broken-image` at `reader/ReaderContent.tsx:10` — a false positive matching
`<img>` inside a code comment.

The failures are not stylistic. They are three surfaces that never received the
system's own treatment.

## Priority Issues

**[P0] The activity calendar was laid out on the wrong axis.** 7 *columns* ×
~52 rows produced a 3,628px vertical ribbon on a 390px phone; no two days could
be compared. The intensity ramp was `brand-tint` (L 0.965) at varying opacity
over `surface-2` (L 0.962) — ΔL 0.003, so the heatmap encoded nothing visible,
and colour was its only channel.

**[P1] Rankings nested a second `<main>` inside the app shell's `<main>`.**
Invalid landmark nesting, and the doubled `app-main` padding set the whole page
16px further in than every other page in the app.

**[P1] Reading stats bypassed the design system.** Inline style objects for
layout, bare `<h2>` with `margin: 0` and no font treatment (UA sans against the
serif h1), `.tally` unused where it was designed for exactly that figure-over-
label strip, retry duplicating the fetch inline.

**[P1] Destructive actions disagreed with each other.** Library's 移出書庫 gave
a toast with 復原. Bookmarks' 刪除 had no confirm, no undo, and swallowed
failures (`.catch(() => undefined)`), leaving the row on screen with no reason.

**[P2] The member subnav drifted across its three pages.** Each listed only the
*other* pages, so nothing marked the current one; 登出 existed on 我的書庫 alone.

**[P2] Registration asked for an invite code that gates nothing** (open beta)
and offered no password reveal on an account with no self-serve reset.

## Persona Red Flags

**Casey (distracted mobile)**: 3,000px of scroll to reach 最近讀過. Rankings
page visibly misaligned against the catalog they just came from.

**Sam (accessibility)**: calendar intensity by colour alone with no legend and
a 0.003 lightness delta; 364 per-cell aria-labels; no current-page marker in the
member nav.

**Riley (stress tester)**: delete a bookmark while offline — the row stays, no
message, no clue.

## Minor Observations

- `.library-page`, `.bookmarks-page`, `.reading-stats-calendar` were class hooks
  with no CSS behind them.
- `role="tab"` without `aria-controls` / `tabpanel` on both Catalog and Rankings.
- Rankings hand-rolled `.empty` markup instead of the shared `EmptyState`.
